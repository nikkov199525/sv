  ┌───────────────────────────────────────────┐
  │ Программа  "SPEAKING VIEWER"  версия  3.5 │
  └───────────────────────────────────────────┘


     Программа  SV  предназначена для чтения текстов не ограниченного
размера.  Программа разработана  Довыденковым Владимиром  при
содействии  Саприна Сергея Гавриловича, Сысолятина Павла и

     Запуск программы осуществляется из командной строки вводом
команды следующего типа:
    SV.EXE  [файл1 файл2 ... файл9]  [/тип_памяти]  [/r]
где:
  файл_n -  это имя файла, который будет загружен в окно
    с номером 1, 2, ..., 9.  Т.е. файл, имя которого написано сразу
    после команды  sv  будет загружен в окно номер 1;  второй файл:
    в окно номер  2  и т.д.  Если необходимо загрузить только один
    файл, то указывается только имя этого файла.
  /тип_памяти -  Вид памяти, которая будет использоваться для загрузки
    файлов и служебной информации;
      /low -  использование нижней памяти,
      /high -  использование верхней памяти,
      /disk -  использование дисковой памяти.
    Если память не указана, просмотрщик использует опцию из файла
    инициализации.
  /r -  Чтение файла сразу после загрузки.  После того, как чтение
    будет прервано, просмотрщик войдет в обычный режим просмотра.

     Перед загрузкой файла программа анализирует файл:
подсчитывается колличество строк, длина самой длинной строки и т.д.
Если размер файла привышает  5 мегабайт, то перед началом анализа
звучит сообщение  "Анализ".  Процесс анализа нельзя прервать и
нельзя определить процент проанализированного.
Если файл загружается как база данных, то он не анализируется.

     Если в качестве параметра задан архивный файл, то его содержимое
может быть извлечено и выведен список файлов.  После чего вы можете
выбрать нужный и нажав  enter  загрузить его в просмотрщик.
Описание командных строк для извлечения файлов из архива задаются
в файле  SV.DCL.

     При загрузке файла программа  SV  подает звуковой сигнал на
динамик.  Этот сигнал продолжается втечении всей загрузки и
прекращается словом "загружено"  и звуковым сигналом другого тона.
Процесс загрузки можно прервать нажатием клавиши  esc  после чего
звучит сообщение  "Прервано..."  и вам необходимо выбрать одну
из кнопок:  "Продолжить", "Прервать"  и  "Выход".
Перемещение по диалоговым кнопкам осуществляется клавишами
горизонтального управления курсором.  Первая кнопка -  "Продолжить"
вызовет продолжение загрузки файла.  Вторая -  "Прервать":  вызовет
прекращение загрузки и вход в программу, но файл будет загружен только
частично.  Третья кнопка -  "Выход" -  вызовет прекращение загрузки и
выход из программы.

     При загрузки файла, просмотрщик проверяет расширение файла и,
взависимости от расширения, файл либо загружается как текст, либо
загружается как база данных, либо как файл редактора  ms-word97,
либо разархивируется.  Если по расширению файл не текстовый, т. е.
он имеет расширение  ".dbf", ".doc"  или расширение архивного файла,
то по каждому из типов файла действует установка  "Контроль...".
При включеном контроле, вы сможете выбрать:  загружать ли файл как
текст  или загружать его (в соответствии с расширением) как
базу данных, текст редактора  ms-word97  или архивный файл.

     После загрузки текста на экране появляется текстовое окно.
На верхней горизонтальной линии рамки, в левой части, в скобках
указан номер текущего окна  (от  1  до  9).  Правее расположены
три индикаторных знакоместа:  вкл/выкл. замены латинских букв на
схожие по написанию русские, вкл/выкл. чтения текста с озвучиванием
всех символов, вкл/выкл. непрерывное горизонтальное перемещение.
Если в индикаторном знакоместе стоит символ  "|" (вертикальная черта),
то установка включена.  На нижней линии рамки слева на право выводится
информация о номере строки, позиции, процентном отношении
прокрученного текста, размере свободной памяти, текущей кодировке.

     В режиме чтения текста используются следующие клавиши:
стрелка_влева -  переход к началу текущего абзаца или к предыдущему
стрелка_вправа -  переход к следующему абзацу
стрелка_вниз -  переход к следующей пустой строке
стрелка_вверх -  переход к предыдущей пустой строке

     В программе реализована поддержка манипулятора  "мышь".
В текстовом окне возможны следующие действия с  "мышью":
одиночный щелчок левой кнопкой -  чтение текущей строки;
двойной щелчок левой кнопкой -  чтение всего текста начиная с
  текущей строки;
одиночный щелчок средней кнопки -  вызов помощи;
двойной щелчок средней кнопки -  вызов разделов помощи;
одиночный щелчок правой кнопки -  вызов главного меню;
двойной щелчок правой кнопки -  выход из программы;
     Нажатие и удерживание правой кнопки при одновременном нажатии
левой кнопки вызовет переход на следующую строку.  Нажатие и
удерживание левой кнопки при одновременном нажатии правой вызовет
переход на предыдущую строку.

2. Главное меню программы        [ 002 ]
========================================================================

помощь
  ┌──────────────┐
  │ Главное меню │
  └──────────────┘


     Главное меню программы  SV  является основным функциональным
инструментом.  Выбрав соответствующую опцию меню можно выполнить
любую функцию программы.

     При вызове, активизируется горизонтальное меню, которое содержит
следующие опции:   "Файл", "Читать", "Блок", "Закладки", "Поиск",
"Окна", "Настройки", "Помощь".  Перемещаясь по опциям горизонтальными
стрелками, выберите нужную вам и нажмите  ENTER.  После чего вы
перейдете в вертекальное меню соответствующей опции.

     Осуществить выбор опции можно спомощью манипулятора  "мышь".
При движении манипулятора в горизонтальном направлении активные опции
будут изменяться.  Выбрав нужную опцию нажмите левую кнопку
манипулятора  "мышь".

     Для выхода из меню используйте клавишу  esc  или правую
кнопку "мыши".

3. Меню "Файл"        [ 003 ]
========================================================================

Помощь
  ┌──────────────┐
  │ Меню  "Файл" │
  └──────────────┘


     В меню  "Файл"  описаны следующие опции:
"Открыть"     открытие нового файла в текущее окно;  если вместо имени
  файла введена маска (шаблон), то будет открыто окно выбора файлов;
"Закрыть"     выгрузка файла из текущего окна;
"Статистика"  вызов окна статистики, в котором сообщаются основные
  данные о файле, загруженном в текущее окно;
  чтение окна статистики осуществляется нажатием клавиши  ctrl+enter;
  выход из окна статистики:  клавиша  esc;
"Выход"       завершение работы программы  "SPEAKING VIEWER".

     Для перемещения по опциям используйте клавиши вертикального
управления курсором.  Для выполнения опции нажмите  enter.
Возврат в горизонтальное меню - клавишей  esc.

Помощь
  ┌────────────────┐

     В этом вертикальном меню можно выбрать объект, для чтения.

5. Меню "Блок"        [ 005 ]
========================================================================

Помощь
  ┌──────────────┐
  │ Меню  "Блок" │
  └──────────────┘


     Это вертикальное меню позволяет работать с блоками.
Блоком считается выделенная часть текста.  При перемещении по строкам
блока звучит сигнал высокого тона.  Если текущая строка является
началом или концом блока, то звучит соответствующее сообщение.

     В меню описаны следующие опций:
"Начало"           обозначает текущую строку текста, как первую
  строку блока;
"Конец"            обозначает текущую строку текста, как
  последнюю строку блока;
"Записать в файл"  записывает выделеный блок в файл, имя которого
  необходимо ввести после вызова этой опции;
"Время"            подсчет времени, которое понадобится для чтения
  выделенного блока.  Результат озвучивается  и выводится на
  экран в строке опции;
"Печать"           печатает блок на принтер;
"Разметить"        размечает блок.

     Если опция  "Конец"  вызывается без предворительной отметки
начала, то блок будет помечен с первой строки текста.
Если будет вызвана одна из опций  "Записать в файл"  или  "Читать",
но блок не отмечен, то прозучит сообщение об ошибки, после чего
программа вернется в текстовое окно.

     Для выбора опции используйте клавиши вертикального управления
курсором.  Для выполнения выбраной опции нажмите  enter.
Нажатие клавиши  esc  вызовет возврат в горизонтальное меню.

6. Меню "Закладки"        [ 006 ]
========================================================================

Помощь
  ┌──────────────────┐
  │ Меню  "Закладки" │
  └──────────────────┘


     В меню определены две функции работы с закладками:
"Список"     эта функция выдает список закладок ранее вложеных
  в текущий файл.  в этот список можно добавить новые закладки,
  удалить старые, перезаложить существующие.  Если закладок в тексте
  нет, то будет предложено вложить новую закладку;
"Отчистить"  очищает файл закладок  SV.VBM  от не существующих
  закладок, которые были вложены в удаленные или перемещенные файлы.

     Для выбора нужной опции используйте клавиши вертикального
управления курсором.  Для вызова опции нажмите  enter.
Возврат в горизонтальное меню -  клавиша  esc.

9. Меню "Настройки"        [ 009 ]
========================================================================

Помощь
  ┌───────────────────┐
  │ Меню  "Настройки" │
  └───────────────────┘


     Программа  SV  имеет гибкую систему настроек.  Все настройки
можно изменить через меню.  Настройки сохраняются в двух файлах:
SV.CFG  и  SV.INI.  В первом файле сохраняются те настройки,
которые не являются существенными в программе.  Во втором файле
настройки записаны в текстовом формате (в стандарте  INI-файлов).

"Общие"      после выбора этой опции будет вызвано еще одно
  вертикальное подменю, в котором можно установить следующие параметры:
    "Память"  тип памяти (нижняя, верхняя, дисковая), которая
      будет использоваться в программе;
    "Разное"  цикличность объектов, авто сохранение, замена символа
      табуляции на пять пробелов, подтверждение на выход, латинские
      в русские, непрерывное перемещение, сигнал точного времени,
      локализацию слов и рабочий каталог программы;
"Интерфейс"  с помощью этой опции можно настроить следующие параметры:
  показ часов, показ процентов, показ координат, показ процентного
  отношения прокрученного текста, показ объема свободной памяти,
  показ кодировки, использование манипулятора "мышь",
  показ курсора на экране;
"Закладки"   в этой опции можно настроить показывать ли строку
  заложения при выдаче списка закладок и будут ли закладки считаться
  глобальными или локальными;
"Речь"       здесь можно установить вкл/выкл  голоса, диктора,
  скорость, ускорение и паузу между фразами;
"Чтение"     настраивается чтение всех окон подряд или только
  текущего, чтение со всеми символами или без, чтение слов
  "пустая", "абзац" или первого слова строки при вертикальном
  перемещении по тексту, чтение полностью всей строки при
  вертикальном перемещении, настройка паузы при чтении пустых строк,
  настройка левого и правого края зоны молчания;
"Звук"       в этой опции можно настроить такие параметры как:
  вкл/выкл звуковых сигналов, вкл/выкл звука заголовка,
  вкл/выкл звука конца текста, вкл/выкл звука перехода к чтению
  следующего окна;
"Загрузка"   здесь описаны тригерные кнопки, настраивающие процесс
  загрузки:  контроль отступа, контроль баз данных, котроль архивов,
  контроль текстов редактора  ms-word97, восстановление позиции
  курсора  и автоопределение кодировки;
"Вид"        здесь можно настроить:  кодировку, в которой будет
  просматриваться текст, пользовательский файл перекодировки  и
  режим  quonted printable;
"Будильник"  опция позволяет настроить до десяти будильников;
"Сохранить"  при выборе этой опции будут сохранены все изменения,
  которые были сделаны во время настройки программы или во время
  работы в программе.

     Для выбора нужной опции используйте клавиши вертикального
управления курсором.  Для выполнения нажмите  enter.
Для возврата в горизонтальное меню нажмите  esc.

13. Ввод имени нового файла        [ 013 ]
========================================================================

Помощь
  ┌─────────────────────────┐
  │ Ввод имени нового файла │
  └─────────────────────────┘


     При вводе имени файла можно использовать маску.  Если вы

эта строка останится в истории на том же месте.  Если же строка была
отредактирована, то она сохраняется как заново введенная.

15. Окно статистики        [ 015 ]
========================================================================

Помощь
  ┌─────────────────┐
  │ Окно статистики │
  └─────────────────┘


     В этом окне сообщается основная статистическая информация о том
тексте, который загружен в текущее окно.  Первая часть этой
информации -  информация о файле:  имя, размер в байтах.  Вторая

длина самой длинной строки, длина самой короткой строки, левый отступ
текста.  Если загружена база данных, то сообщается колличество
записей, колличество полей в базе данных, дата последнего
редактирования базы, размер всей записи.  Последняя строка в окне,
не зависимо от режима, сообщает ориентировочное время, которое
понадобится для чтения текста.

     Для чтения всего окна используйте клавишу:  ctrl+enter  или
ctrl+j.  Нажатие цифры вызовет чтение одной строки окна.
Для выхода из окна статистики нажмите  esc.

18. Диалог ввода имени новой закладки        [ 018 ]

  └───────────────────────────────────┘

     В этой диалоговой области определены два диалоговых поля.
В поле  "Строка"  вводится подстрока, которую нужно будет искать
в тексте.
Во втором поле -  "установки" -  настраивается способ и направление
поиска.

     В поле  "установки"  возможны следующие настройки:
"Различать регистр" -  установка, которая определяет будет ли при
  поиске учитываться нижний или верхний регистр букв искомой строки;
"Поиск в прямом направлении" -  эта установка определяет в прямом
  (вниз)  или обратном (вверх)  направлении будет производиться поиск;
"Начать поиск с текущей строки" -  установка, определяющая будет ли
  поиск начинаться с текущей строки или, в зависимости от
  предыдущей установки, с первой либо последней строки.
"Искать начало строки" -  эта установка определяет искать ли введенную
  строку внутри строк текста или с начала строк текста.

     Переход между полем  "Строка"  и  полем  "Установки"
осуществляется нажатием клавиши  tab.

     Переключение значения кнопки осуществляется нажатием
клавиши  пробел.  Для перемещения между кнопками используйте
клавиши вертикального управления курсором.

     Находясь в диалоговом поле  "Строка", вы можете
восстановить любую из десяти введенных ранее строк.  Если
восстановленная строка вводится без изменений, то история строк
остается не изменной.  Если же восстановленная строка была перед
вводом отредактирована, то она записывается в историю
как нововведенная.

25. Диалоговая область "Разное"        [ 025 ]

Помощь
  ┌──────────────────────────────┐
  │ Диалоговая область  "Разное" │
  └──────────────────────────────┘


     Эта область состоит из четырех полей.  Первое поле:  семь
тригерных кнопок; второе - радио кнопки, третье и четвертое поля -
строки редактирования.

     В первом поле настраиваются следующие параметры:
"Цикличные меню" -  определяет будут ли цикличными такие объекты как
  Горизонтальное меню, Вертикальное меню, Тригерные кнопки,
  Радио кнопки  и т.д.   Иначе говоря:  будет ли курсор при достижении
  верхней (нижней) границы этого объекта перемещаться на последний
  (первый) элемент этого объекта;
"Авто сохранение" -  определяет будут ли измененные параметры
  сохраняться при выходе из программы;
"Заменять символ табуляции" -  определяет будет ли заменяться символа
  с кодом  #9  на пять пробелов или нет;
"Подтверждение выхода" -  определяет будет ли при выходе
  из программы выдаваться запрос на подтверждение;
"Латинские в русские" -  устанавливает будут ли заменяться символы
  латинского шрифта на русские ("c" на "с", "y" на "у");
"Непрерывное перемещение" -  задает, будет ли горизонтальное
  перемещение по строке ограничиваться справа, или, по достижении
  правой границы курсор перейдет на первый символ следующей строки;
"Сигнал точного времени" -  включает/выключает сигнал точного времени.

     Во втором поле описаны радио кнопки, устанавливающие способ
локализации слов при горизонтальном перемещении клавишами
ctrl+стрелка_вправо, ctrl+стрелка_влево.  При локализации слов,
перемещение производится от знака припинания до знака припинания.
При локализации интервалов локализируется промежуток между пробелами.

     В третьем поле задается временный каталог программы,
в котором будут создаваться  файлы  и/или  каталоги временно
необходимые программе.

     В четвертом поле, через запятую, указываются два значения
"Прыжка".  Первое значение используется для перемещения на
определенное им число строк при нажатии клавишь  ctrl+PgUp  или
ctrl+PgDn, а второе значение для определения колличества строк
при прыжке клавишами   shift+PgUp  или  shift+PgDn.

     Переход между полями в области осуществляется нажатием
клавишей таб и shift+tab.  Выход из области с применением всех
установленых параметров осуществляется нажатием клавиши  enter.
Выход без применения параметров:  клавиша  esc.

28. Настройки речи        [ 028 ]
========================================================================

Помощь
  ┌────────────────┐
  │ Настройки речи │
  └────────────────┘


     Область состоит из пяти полей, переход между которыми
осуществляется нажатием клавишь  tab  и  shift+tab.

     Первое поле состоит из одной тригерной кнопки, определяющей
озвучивание программы речью.  Изменить статус кнопки можно нажатием
клавиши  пробел.  Второе поле -  группа из четырех радио кнопок,

стрелка_влево,  стрелка_вправо ("медленнее" или "быстрее"
соответственно).  Нажатие клавиши  home  приведет к установке
самой медленной скорости,  а нажатие клавиши  end:  к установке
самой быстрой.
Четвертое поле -  ускорение речи поверх темпа:  от  -3 до +7
(0:  нормально,  плюс:  быстрее,  минус:  медленнее).
Пятое поле -  пауза между фразами:  от  0 до 255  (100:  обычная,
меньше:  короче,  больше:  длиннее)  или  "авто"  -  пауза зависит
от ускорения.  Ускорение и паузу меняют те же клавиши, что и
скорость.  Вне настроек скорость меняют  ctrl+[  и  ctrl+],
ускорение -  ctrl+alt+[  и  ctrl+alt+],  паузу -  ctrl+shift+[  и
ctrl+shift+]  (правая скобка -  число больше).

     Все изменения реализуются после нажатия клавиши  enter.
Для отмены нажмите  esc.

34. Настройка процесса загрузки        [ 034 ]
========================================================================

Помощь
  ┌─────────────────────────────┐
  │ Настройки процесса загрузки │
  └─────────────────────────────┘


     В этой области определены шесть тригерные кнопки, настраивающих
процесс загрузки файла.
"Контроль отступа" -  при включеном контроле, программа, при
  загрузки текста, проверит существует ли постоянный левый отступ.

  обнаружении отступа программа это проигнорирует.
"Контроль баз данных" -  устанавливает контроль за загрузкой базы
  данных формата  DBF.  При включеном контроле файлы с расширением DBF
  будут загружаться в зависимости от ответа на запрос, либо как
  база данных, либо как обычный файл.
  При выключеном контроле файл с расширением  DBF  будут автоматически
  загружаться как база данных.
"Контроль архивов" -  кнопка настраивает контроль архивов.
  Т.е. если в качестве параметра просмотрщику задать архивный файл,
  описанного в файле  sv.dcl  формата, то при включенном
  контроле архивов просмотрщик запросит подтверждение:  загружать
  ли этот файл просто как файл, или распаковать его и выдать
  список содержимого для загрузки в просмотрщик.  При выключенном
  контроле архивов такого подтвержения не потребуется и файл
  будет разархивирован.
"Контроль файлов  Word 97" -  эта кнопка определяет необходимость
  запроса при загрузки файла с расширением  doc.  При включеном
  контроле, перед загрузкой файла, программа запросит подтвеждение
  на загрузку этого файла как файла редактора  MS-Word 97.
  При выключенном контроле файл будет загружен без запроса.
"Восстанавливать позицию" -  эта кнопка определяет будет ли
  сохраняться, а в последствии восстанавливаться, позиция курсора
  в файле.
"Автоопределение кодировки" -  определяет автоматическое определение
  кодировки, в которой написан текст.

     Выход с применением установок клавишей  enter.  Если вы хотите
выйти без сохранения изменений в области - нажмите клавишу  esc.

35. Установка будильника        [ 035 ]
========================================================================

Помощь
  ┌──────────────────────┐
  │ Установка будильника │
  └──────────────────────┘


     В этой диалоговой области описаны три поля:
первое поле состоит из двух тригерных кнопок; второе поле - это
строка редактирования, в которой следует задать час и минуты
срабатывания будильника разделенные символом  ":"  (двоеточие).
третье поле - строка редактирования, в которой задается сообщение
будильника.

     Первая кнопка в первом диалоговом поле задает включение
будильника.  Если эта кнопка вкючена, то будильник бует "взведен".
Вторая кнопка задает одноразовое или многоразовое использование
будильника.  Т. е. если кнопка "Постоянная работа"  включена, то
будильник будет срабатывать всегда.  Если же  "Постоянная работа"
выключена, то после первого срабатывания будильник выключится.

     Во втором поле задается время, на которое заведен будильник.
Время необходимо указывать через символ ":"  (двоеточие).
Час и минуты обязательно должны быть двузначными числами.
Например:  06:00.

     В третьем поле задается сообщение, которое произнесет
будильник при срабатывании.  Если сообщение не указано, то
при срабатывании будет звучать только звуковой сигнал.

     Переход между диалоговыми полями осуществляется клавишами  tab
и  shift+tab.

     Если вы уверены в правельности установок, нажмите  enter.
Если же вы хотели бы отменить все внесенные вами изменения, нажмите
клавишу  esc.  После выхода из области вы вернетесь в меню
будильников.

37. Файл описания замен        [ 037 ]
========================================================================

Помощь
  ┌─────────────────────┐
  │ Файл описания замен │
  └─────────────────────┘


     В файле описания заменяемых и заменяющих фрагментов  (sv.chf)
необходимо указывать какие фрагменты строки нужно заменять и
на какие.

     Описывать необходимо по следующим правилам:  фрагмент, который
нужно будет заменять должен быть заключен в символы  "#" (номер/диез).
На следующей строке (также с начала строки) необходимо указать
фрагмент, на который будет заменен выше указанный, причем
этот фрагмент должен начинаться и заканчиваться символом "^" (крышка).

     Пример файла:
#т.д.#
^так далее^
#т.п.#
^тому подобное^
#и пр.#
^и прочее^



     Символ  "@"  (собака/эт), указанный перед искомым фрагментом
определяет режим регистронезависимости при поиске.  То есть, выражение
@#xxx#
будет заменено на другое, независимо от регистра букв  "xxx".

     Любые отступления от выше указаных правил могут привести к
самым непредсказуемым заменам в тексте.

     Для того, чтобы использовать ваш файл описания замен его необходимо
подключить.  Для этого в окне текста нажмите клавишу  alt+f9  и введите
или отредактируйте строку.

     Включение и выключение режима замены фрагментов осуществляется
нажатием клавиши  f9  в текстовом окне программы, либо
соответствующей настройкой параметра  Change_Frag  файла
инициализации.

38. Файл описания распаковки        [ 038 ]
========================================================================

Помощь
  ┌──────────────────────────┐
  │ Файл описания распаковки │
  └──────────────────────────┘


     В файле распаковки  sv.dcl  описываются командные строки, при
вызове которых будет распаковываться архивный файл заданый программе.
Формат описания командной строки:
расширение:  командная строка

     При вызове программы просмотрщик ищет расширение заданного файла
в файле распаковки.  Если такое расширение найдено, то просмотрщик
считает загружаемый файл архивным.  При распаковки файла просмотрщик
создает директорию  <Temp_Directory>\arc   в которую распаковывает
содержимое файла.  Файл распаковывается командной строкой заданной
в файле распаковки.  Командная строка при описании может содержать
следующие макросы:
<archive> -  имя распаковывающегося файла;
<directory> -  задает директорию назначения  (<temp_directory>\arc).

     В программе эти макросы заменяются на имя архивного файла  и
на временный каталог, в который будут распаковываться файлы и который
будет удален после работы просмотрщика.

39. Пользовательские файлы перекодировки        [ 039 ]
========================================================================

Помощь
  ┌──────────────────────────────────────┐
  │ Пользовательские файлы перекодировки │
  └──────────────────────────────────────┘


     Пользовательские файлы перекодировки предназначены для
перекодировки текста, загруженного в просмотрщик.  Перекодировка - это
замена одного символа на другой.

     Файл перекодировки должен иметь следующую структуру:  каждый
нечетный байт в файле перекодировки будет заменять каждый предыдущий,
четный байт.  Например, нулевой байт будет заменяться на
первый и  т. д.

     Для активизации перекодировки необходимо указать имя
пользовательского файла перекодировки либо в файле инициализации
(строка "User_Decode"), либо в диалоговом поле
"Настройки"/"Вид"/"Файл перекодировки".  Либо в диалоговом поле,
вызваном клавишей  Ctrl+f8.  Затем необходимо сменить режим
перекодировки на "Пользовательский".  Это можно сделать либо в файле
инициализации (строка "Code= User_Recoding"), либо нажимая
клавишу  F8  в текстовом окне, либо в диалоговом
поле "Настройки"/"Вид".

41. Диалоговые кнопки        [ 041 ]
========================================================================

Помощь 
  ┌───────────────────┐ 
  │ Диалоговые кнопки │ 
  └───────────────────┘ 
 
 
     В диалоговых областях программы используются три типа 
диалоговых кнопок.  Первый тип:  тригерные кнопки - состоят из 
двух частей: названия и статуса.  При переходе на тригерную кнопку 
звучит ее название и статус (включена-выключена).  Нажатием клавиши 
пробел  можно изменить статус на противоположный. 
Второй тип диалоговых кнопок:  радио кнопки.  Число радио кнопок 
всегда больше одного.  Из списка кнопок в диалоговом поле может 
быть активной только одна кнопка.  После чтения названия активной 
кнопки из вертикального списка кнопок звучит короткий звуковой сигнал 
высокого тона.  Для того чтобы сделать текущую кнопку активной 
необходимо нажать пробел.  
Третий тип не имеет названия.  Эти кнопки расположены горизонтально 
и используются также, как и горизонтальные меню. 
При горизонтальном перемещении по кнопкам звучит их название. 
Выбрав нужную кнопку и нажав  enter  вы вызовете действие связаное 
с этой кнопкой.  Частным случаем использование кнопок является 
запрос на подтверждение.  Этот запрос состоит из сообщения и двух 
кнопок:  "Да"  и  "Нет".  Выбрав кнопку горизонтальным перемещением 
и нажав  enter  вы либо подтвердите, либо откажитесь от действия, 
объявленного в сообщении.  Еще одним распространенным в программе 
случаем использования кнопок является  "сообщение".  Такое сообщение 
используется для уведомления пользователя о результате выполненой 
процедуры.  "Сообщение"  состоит из собственно уведомления и одной 
кнопки  "ОК", нажав которую вы выйдете из  "Сообщения". 
При использовании в окнах кнопок действует клавиша  ctrl+s, нажав 
которую вы вызовете чтение сообщения.  Клавиша  esc  в окне 
подтверждения будет воспринета как нажатие кнопки  "нет".

42. Меню        [ 042 ]
========================================================================

Помощь

  │ Меню │

     В программе используются два типа меню:  горизонтальное и

вертикальном меню вызовет переход в следующее или предыдущее 
вертикальное меню.

43. Файлы инициализации и конфигурации        [ 043 ]
========================================================================

Помощь
  ┌───────────────────────────────────────┐
  │ Файлы  инициализации  и  конфигурации │
  └───────────────────────────────────────┘


     Все настройки программы  "SPEAKING VIEWER"  хранятся в двух
файлах:  sv.cfg  и  sv.ini.  В файле  sv.cfg  (файл конфигурации)
хранятся те параметры, которые не могут быть настроены.
Файл  sv.ini  (файл инициализации) -  обычный текстовый файл,
в котором можно простым редактированием изменить настройки программы.

     Файл инициализации делится на области.
Ниже приведено описание всех настроек.

[GENERAL] -  общие настройки
InvokedMemory=
    используемая программой память.
    Возможные значения:  Low -  нижняя память, High -  верхняя память,
    Disk -  дисковая память.
Temp_Directory=
    этот параметр задает временный каталог, в котором будут,
    по необходимости, создаваться временные файлы  и/или подкаталоги.
CycleObj=
    настройка цикличности диалоговых объектов.
    Возможные значения:  On -  включено, Off -  выключено.
AutoSave=
    Автосохранение параметров  (при включеном параметре перед
    выходом из программы все настройки будут сохраняться
    автоматически).
    Возможные значения:  On -  включено, Off -  выключено.
Tab=
    При вкюченой установке  символ табуляции  (ASCII #9) будет
    заменяться на 5 символов пробела  (ASCII #32).
    Возможные значения:  On -  включено, Off -  выключено.
ExitConfirm=
    Подтверждение на выход из программы.
    Возможные значения:  On -  включено, Off -  выключено.
Latin2Russ=
    Замена латинских букв на схожие по написанию русские буквы.
    Возможные значения:  On -  включено, Off -  выключено.
NoStop=
    Непрерывное горизонтальное перемещение  (по достижению конца
    строки курсор переходит на начало следующей).
    Возможные значения:  On -  включено, Off -  выключено.
Jump=
    Задание колличества строк, на которое нужно будет переместиться
    при нажатии клавишь  Ctrl+PgDn(PgUp)  и  Shift+PgDn(PgUp).
    Параметры задаются через запятую, и должны быть числами
    более нуля.
Exact_Time=
    Сигнал точного времени.
    Возможные значения:  On -  включено, Off -  выключено.
Local=
    Локализация.  При горизонтальном перемещении клавишами
    Ctrl+стрелка_вправо  и  Ctrl+Стрелка_Влево  можно перемещаться
    либо по словам, либо по интервалам.  Слово -  промежуток от
    знака припинания до знака припинания;  интервал -  промежуток от
    пробела до пробела.
    Возможные значения:  Word -  слово, Interval -  интервал.

[INTERFACE] -  настройки интерфейса
Clock=
    Этот параметр настраивает часы.  При включеной установки -
    часы будут выводиться в верхний правый угол экрана.
    Возможные значения:  On -  включено, Off -  выключено.
Mouse=
    Использовать ли манипулятор "мышь" в работе программы
    (драйвер "мыши" должен быть загружен).
    Возможные значения:  On -  включено, Off -  выключено.
Cursor=
    Показывать ли курсор.  Независимо от настройки курсор будет
    показываться в диалоговых областях.
    Возможные значения:  On -  включено, Off -  выключено.
PerCent=
    Выводить ли информацию о процентном отношении прокрученного
    (прочитанного) текста на нижнюю черту рамки.
    Возможные значения:  On -  включено, Off -  выключено.
Coords=
    Выводить ли номер строки и номер позиции на нижнюю
    черту рамки.
    Возможные значения:  On -  включено, Off -  выключено.
FreeMemory=
    Отображать ли объем свободной памяти на нижней черте рамки.
    Возможные значения:  On -  включено, Off -  выключено.
Code=
    Выводить ли информацию о текущей кодировке на нижнюю
    черту рамки.
    Возможные значения:  On -  включено, Off -  выключено.

[BOOK-MARK] -  настройки закладок
Global=
    При включеной установке в список закладок будут выписываться
    те закладки, которые были вложены в файл с тем же именем,
    что и загруженый.  Если эта установка выключена, то будут
    выписаны закладки, вложеные в файл с таким же путем, как и
    у загруженного файла.
    Возможные значения:  On -  включено, Off -  выключено.
ShowLine=
    Установка, настраивающая вывод номер строки, на которую была
    вложена закладка.  То есть, при включеной установке в списке
    закладок, после имени закладки будет указываться номер
    строки, на которую закладка была вложена.  В противном
    случае будет выведено только имя закладки.
    Возможные значения:  On -  включено, Off -  выключено.

[SINTEZIZER] -  настройки речи
Talk=
    Включить или выключить речь в программе.
    Возможные значения:  On -  включено, Off -  выключено.
Dictor=
    Номер дикторского голоса.
    Возможные значения:  0 -  мужской тенор, 1 -  женский
    сопрано, 2 -  мужской баритон, 3 -  женский альт.
VoiceDirectory=
    Директория, где лежали дикторские файлы  male.dat  и  female.dat.
    Больше не используется:  голоса встроены в программу.
Speed=
    Скорость речи.
    Возможные значения:  от 0 (самая медленная)  до 150
    (самая быстрая).  Вместо прежнего ключа  Temp=,  у которого
    шкала была обратной:  0 -  самый быстрый темп.
Acceleration=
    Ускорение речи поверх скорости.
    Возможные значения:  от -3 (медленнее всего)  до +7 (быстрее
    всего),  0 -  нормально.  Вместо прежнего ключа  Accel=
    (от 13 до 3,  10 -  нормально).
Pause=
    Пауза между фразами.
    Возможные значения:  от 0 до 255,  100 -  обычная,  больше -
    длиннее;  Auto -  зависит от ускорения.

[READING] -  настройки чтения
EmptyLine=
    При включенной установке, при попадании на пустую строку
    будет произнесено слово  "пустая".  В противном случае прозвучит
    звуковой сигнал низкого тона.
    Возможные значения:  On -  включено, Off -  выключено.
Indent=
    При включенной установке, при попадании на абзац
    будет произнесено слово  "абзац".  В противном случае прозвучит
    звуковой сигнал среднего тона.
    Возможные значения:  On -  включено, Off -  выключено.
FirstWord=
    При вертикальном перемещении по строкам, если строка не
    пустая и не абзац, при включеной установке будет читаться первое
    слово строки.  При выключеной установке будет звучать короткий
    звуковой сигнал высокого тона, слышымый как щелчек.
    Возможные значения:  On -  включено, Off -  выключено.
Line=
    Читать ли при вертикальном перемещении всю строку.
    Возможные значения:  On -  включено, Off -  выключено.
ReadSpaceBar=
    При озвучивании символа  "пробел"  будет произнесено  "ПБ".
    При выключеной установке будет звучать сигнал.
    Возможные значения:  On -  включено, Off -  выключено.
Symbols=
    Произносить ли при чтении все знаки или нет.
    Возможные значения:  On -  включено, Off -  выключено.
WinByWin=
    При включеной установке после окончания первого текста,
    начнется чтение текста, загруженного в следующее окно.
    Возможные значения:  On -  включено, Off -  выключено.
Capital=
    Сигнализировать ли при чтении заглавных букв.
    Возможные значения:  On -  включено, Off -  выключено.
AOS=
    Определение зоны молчания.  То есть части строки (от символа
    с номером  n  до символа с номером  m), которая не будет
    читаться не при чтении строки, не при чтении текста.
    Значения задаются так:  N-M, где  n -  номер первого символа
    зоны молчания, а  m -  последний символ зоны молчания.
Empty_Delay=
    Здесь задается длительность паузы при чтении пустых
    строк текста.
    Значение задается в  1/18  секунды  (55 миллисекунд).

[STARTUP] -  настройка загрузки
Indent_Control=
    Контроль отступа.  При включеном контроле, перед загрузкой текста
    проверяется существует ли постоянный отступ или нет.  Если отступ
    существует, то вам будет предложено загрузить текст без отступа.
    Если контроль отступа выключен, то постоянный отступ в тексте
    будет игнорироваться.
    Возможные значения:  On -  включено, Off -  выключено.
DBF_Control=
    Контроль базы данных формата  DBF.  Если контроль включен, то
    при загрузке базы данных будет выдано предупреждение и предложено
    либо продолжить загрузку файла как базы данных, либо как текста.
    Если контроль выключен, то файл с расширением  ".DBF"  будет
    сразу загружен как база данных.
    Возможные значения:  On -  включено, Off -  выключено.
Arc_Control=
    Если контроль архивов включен, то при загрузке файла с расширением
    архивного файла, вам будет предложено выбрать:  либо продолжать
    загрузку файла как архивного  (то есть распаковать содержимое и
    выдать список файлов и каталогов), либо загрузить этот файл
    как текстовый.
    Возможные значения:  On -  включено, Off -  выключено.
Doc_Control=
    При вкюченном контроле  doc-файлов, перед загрузкой файла с
    расширением  ".DOC"  вам будет предложено либо продолжить
    загрузку файла как текста редактора  word 97, либо загрузить
    файл как обычный текстовый файл.
    Возможные значения:  On -  включено, Off -  выключено.
Word97_StLen=
    Эта установка необходима только при загрузки текстов редактора
    word 97.  Она задает среднюю длину строки текста.
    Максимальная длина строки при этом будет  Word97_StLen +8,
    а минимальное -  Word97_StLen -16.
    Возможные значения:  от 24  до 250.
Old_Posit=
    Сохранять (а затем восстанавливать)  позицию курсора в тексте.
    Возможные значения:  On -  включено, Off -  выключено.
AutoDetect_Code=
    Автоматическое определение кодировок.  Точность определения
    очень высока.
    Возможные значения:  On -  включено, Off -  выключено.
