# Speaking Viewer
Это знакомая в узких кругах утилита для чтения текста Speaking Viewer, переписанная на c++.
Изначальные авторы: Довыденков в, Саприн С.Г, Сысолятин П, С. Картавцев и С. Шишминцев.
Интерфейс, клавиши, звуки и все сообщения программы перенесены без изменений.
## Отличия от старой версии
Главное отличие- это то, что программа переписана на c++. Теперь UTF-8 и внутри программы, и снаружи: тексты, имена файлов, консоль, настройки, при этом поддержка DOS-866, Windows-1251, KOI8-R также сохранена. Это позволило успешно собрать эту программу и под linux.


* справка в обычном  текстовом файле `SV_help.txt` рядом с программой.

## Ускорение и паузы речи
Задаются в `SV.INI`, раздел `[SINTEZIZER]` (на Windows файл лежит рядом с `SV.exe`, на Linux — `~/.config/sv/SV.INI`) и работают как ключи `accel` и `pause` старого драйвера SDRV:
```
Accel= 10
Pause= -1
```
* `Accel` — ускорение поверх темпа, 3..13: 10 — нормально, меньше — быстрее (4 — максимальное ускорение), больше — медленнее (13 — максимальное замедление).
* `Pause` — паузы между фразами, 0..255: 100 — обычные, меньше — короче, больше — длиннее; -1 — как у драйвера: пропорционально `Accel`.
Темп (`Temp=`, «Настройки» → «Речь», Ctrl+[ и Ctrl+]) действует отдельно, ускорение — поверх него. Если от прежних версий остался файл `newfon.cfg` с этими параметрами, программа возьмёт значения из него и при сохранении настроек перенесёт в `SV.INI`.

## Сборка
### Windows
Требуется CMake 3.25+ (`winget install Kitware.CMake`) и один из тулчейнов:
* llvm-mingw `winget install MartinStorsjo.LLVM-MinGW.UCRT`;
* Visual Studio 2022+ с нагрузкой «Разработка классических приложений на C++».
Сборка производится следующим образом.
* 1. Склонировать этот репозиторий:
```
git clone --recursive https://github.com/nikkov199525/sv
```
В уже склонированном: `git submodule update --init`.
* 2. Запустить один из батников:

```
build_x86.bat [-b mingw|msvs] [keep]
build_x64.bat [-b mingw|msvs] [keep]
build_all.bat [-b mingw|msvs] [keep]
```
Здесь и далее ключи опциональны.
То же из командной строки:
```
cmake -P cmake/build.cmake x86|x64|all [-b mingw|msvs] [keep]
cmake -P cmake/build.cmake check [x86|x64|all] [-b ...]     собрать и проверить
cmake -P cmake/build.cmake clean
```

### Linux
Сборка проверена на Debian 13.7 x64.
* 1. Установить необходимые инструменты, если их нет:
```
sudo apt install cmake build-essential dpkg-dev
```
* 2. Склонировать этот репозиторий:
```
git clone --recursive https://github.com/nikkov199525/sv
```
В уже склонированном: `git submodule update --init`.

* 3. Перейти в папку со склонированным репозиторием. Сборка и установка — одной командой:

```
./build.sh install
```

Остальные варианты:

```
./build.sh [x64|x86|all|check|install|clean] [keep]
```
Затем можно установить пакет.
```
sudo apt install /полный/путь/sv_reborn/build/sv_*_amd64.deb
```

Теперь можно запускать sv в терминале
```
sv [/r] [файл...]      запуск; sv --help — ключи, man sv — подробно
```
